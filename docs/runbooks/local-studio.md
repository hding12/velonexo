# 本地媒体管理页

> 目录迁移说明：当前命令从 `code/` 执行；旧 `.local/` 对应 `../local/runtime/`，旧根 `.env.local` 对应 `../local/secrets/.env.local`，实际目录在 `../local/catalog/videos.json`，实际存储配置在 `../local/config/storage.json`。新克隆默认布局及最新操作以 [工作区布局](workspace-layout.md) 为准。


入口：`http://127.0.0.1:5174/studio`，启动方式仍为 `npm run dev`。依赖 `.venv`、FFmpeg 和离线发布工具；安装步骤见 local-demo.md。

## 操作

1. 选择视频文件，填写标题、作者、分类与逗号分隔的标签。
2. 选择「Solo en este equipo」保存本机，或选择已配置的单个存储/分布式存储。
3. 点击「Preparar borrador」。上传后显示实际的准备、上传、校验和目录写入阶段；不显示虚假的编码百分比。
4. 完成后出现在 Biblioteca，状态为 Borrador。可预览和编辑信息。
5. 点击 Publicar，工具先验证媒体再发布；Retirar 撤下但保留媒体，随后可重新 Publicar。
6. Actualizar reproducción 可重新校验并生成播放清单；当前HF公开地址无需定时续签。

每次最多一个任务；文件上限250 MB。处理失败不会发布新条目。完整收到文件后发生的失败可以点击 Reintentar，沿用同一视频ID和保存的参数；未完整接收或历史版本未保留文件的任务需要重新上传。没有自动重试。浏览器离开不停止已接收的任务，重新打开页面可查看状态；停止/重启开发服务器会中断任务并标为失败。

## 实现边界

这是 V0.2 的本地操作原型，不是已部署的多用户后台：没有 Supabase、账号登录、角色权限、数据库迁移或公网管理服务。外链继续暂停，页面不接受外链导入；举报不恢复。

API只在Vite开发服务挂载，校验loopback连接、Host、Origin和请求会话令牌。不接受任意命令或路径；用固定Python程序和参数数组启动任务。上传文件放`.local/studio/uploads`，处理成功后清除临时副本；失败时保留已完整接收的副本供重试，原片备份仍由发布工具管理。凭据不进入浏览器；错误输出不返回SDK原文。

任务记录在`.local/studio/jobs.json`，保留失败任务的恢复信息；正在执行的任务不会在重启后自动重新上传。重启时核对已经入库的上传任务，避免重复建条目。当前没有跨机器队列或断点续传。

目录写入复用CLI锁和原子备份逻辑。草稿与撤下条目仍存在于本地JSON中，不是内容访问保密措施。网页暂不提供源文件永久删除，删除当前版本仍使用离线 purge。

## 失败恢复与清理

活动列表会区分文件无法读取、连接/权限、容量上限、完整性校验、资源缺失、超时和服务中断等原因。错误码是白名单，不返回SDK原始错误或签名URL。

- Reintentar：复用原任务参数与视频ID。处理失败的完整接收文件仍保留；成功后移除接收副本。普通编辑/发布等失败同样可重试。
- Limpiar restos：需确认后执行，仅用于从未进入目录的失败上传；已入库的草稿、已发布及已撤下条目均拒绝此路径。清理接收副本、工作文件及台账中记录的远程对象，保留原片备份。
- 清理中断可重试，已删除对象有台账标记。对没有映射或提供商目标已改变的对象拒绝盲删。
- 超时先终止进程，等待退出后释放任务占用；不是让旧进程后台继续写入。

## 批量管理

Biblioteca 支持标题/作者/标签搜索及发布状态筛选。可选择最多50条批量发布或撤下；改变筛选条件会清除当前选择。批量发布先验证所有选中媒体，全部成功才一次性更新目录；失败不会只发布其中一部分。验证过程中更新的临时播放清单不属于目录发布状态变更。

## 存储管理

Almacenamiento 显示每节点项目台账用量与配置上限；不是账户账单或供应商实际剩余额度，失败上传的已尝试对象也保守计入。活动中显示转码后计算的本次远程新增容量预估。

- Comprobar conexión：创建小型合成文本对象，验证GET哈希、HEAD、Range、CORS后删除。展示检测时间与结果。
- Pausar nuevas cargas：只从后续上传分配中排除该节点，不改变现有映射、读取地址或刷新能力。
- Habilitar nuevas cargas：重新允许分配。所有节点暂停后仍可选本机存储；不自动创建或付费开通新节点。

## 网页目录恢复

Studio 下方的 `Respaldos de la biblioteca` → `Ver respaldos` 列出自动备份的时间、条目数和已发布数。选择版本后需在弹窗中确认；恢复沿用任务队列及发布工具锁。先校验目标目录与已发布媒体，通过后备份当前目录并原子替换。失败时当前目录不变，活动列表显示错误并支持重试。

此功能恢复整个目录（含外链草稿），不恢复媒体文件、存储配置或互动数据。后续新增条目可能从目录中消失，但不会因此删除远程对象。接口仅接受备份目录中的固定格式文件名，不接受任意路径或符号链接。

## 播放统计与预热

Studio 的 Rendimiento de reproducción 显示当前浏览器最近200次已结束的播放记录；可刷新或清空。不上传观看记录，不视为全站统计。首帧优先使用 requestVideoFrameCallback，切换从卡片激活计时，浏览器不支持时退到 playing 事件。HLS 重试按失败请求后的实际加载器重发计数，原生播放器无法观测全部内部请求。

预热只针对下一条，停留1.2秒后开始；读取清单、初始化块、首段，按响应长度控制512KiB单次和4MiB单页预算；超过长度取消，不保证撤回网络栈已在途字节。切换/页面隐藏取消当前预热，5秒超时。省流量、低于4G类型或低于2Mbps跳过；Safari原生播放暂跳过，避免无法保证缓存复用的额外流量。HLS通过内存缓存消费预取结果；仅保留下一条资源，不保存到磁盘。

验证命令：`node tests/browser/playback-metrics.cjs`、`node tests/browser/preload-check.cjs`、`node tests/browser/preload-budget.cjs`。

## 分类标签与发布历史

Categorías y etiquetas 可改名、合并和上移排序。合并同步目录内所有状态的视频引用并去重；探索页读取保存的顺序。改动通过同一任务队列与发布锁执行。

页面顶部 Motivo de los cambios 用于填写本次原因；Historial de publicación 展示时间、操作、原因、修改前后和分类元数据。CLI 可用 `--reason`（放在子命令之前）指定原因。历史从功能加入时开始，不追造以前的操作；当前身份仅为 local-operator，不冒充已登录用户。记录保存在 `.local/publisher/events`，不会导出进静态站点。写入先登记prepared，再提交目录，最后标记applied；中断记录显示待确认，下次目录写入前根据哈希补全已提交记录。

验收：`node tests/browser/studio-history.cjs`、`node tests/browser/studio-taxonomy.cjs`；Python测试覆盖目录提交失败保留原状态、分类合并和非法排序拒绝。

## 精选、专题与本机热门

Destacados y colecciones 支持精选成员/顺序、专题创建/编辑/删除及成员顺序。选择可包含草稿，但前台只显示已发布条目；静态导出会去掉未发布成员ID。目录中的 editorial 随目录备份、恢复，并进入操作历史。

前台 Destacados 按人工精选顺序，Colección 按专题成员顺序。Más vistos aquí 根据当前浏览器最近200条记录中7天内、至少播放3秒、未失败的会话计数排序；同分按发布时间。它是本机演示的热度，不代表全站人气；外链不计入，短暂停留不计入。全站采集仍需未来正式服务。
