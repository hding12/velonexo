**Goal:** 完成已列出的全部可独立推进任务并自验；真实手机、用户真实素材、新账户和公开上线不作为已完成项。
**Architecture:** 静态目录 + 本地离线 CLI + 现有 Tigris/HF 适配器；版本化映射和媒体包；React/Zyncat 保留。只有本地开发服务器提供本地生成包，签名不进入源码。
**Tech Stack:** Python/FFmpeg/boto3/HF SDK, React/TypeScript/Vite/hls.js, unittest/Playwright.

## 执行顺序
1. scripts/media_publish.py + scripts/media_storage.py + config/storage.json；Python 单元与真实小样例验收。
2. src/components/NativePlayer.tsx + 服务 schema；浏览器有声/无声和故障验证。
3. /explore 与 UI 文案；更新现有浏览器测试。
4. 批量 fixture 生成、全套验收和 docs/runbooks/local-demo.md；最后逐条审计。

每一阶段记录实际命令与结果。不创建远程仓库、不公开发布、不注册服务、不改用户密钥。现有工作区没有 Git 仓库，不假称提交或回滚部署成功。
